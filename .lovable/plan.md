# Fix the downloaded Print Form PDF layout

## Confirmed cause

The uploaded `ENFA-100122_2.pdf` was generated by the latest exporter: it contains the new A4 border, page footer, and DRAFT watermark. However, the exporter still captures the entire on-screen document as one long bitmap and cuts that bitmap into pages. The saved Detailed Description also contains a large embedded image showing an older Print Form and the application sidebar. That image is being preserved at a dominant size, so the downloaded result still visually resembles the old layout and forces the approval grid and comments into poor page positions.

## Implementation

1. **Build stable A4 pages before PDF capture**
   - Replace continuous-canvas slicing with a PDF-only paginated document structure.
   - Use the reference page width, 15 mm side margins, outer border, compact Arial typography, company heading, dynamic right-aligned logo, grey `NOTE FOR APPROVAL` band, field spacing, approval grid, comments spacing, and footer.
   - Keep rows, approval cells, comment/version groups, tables, and images intact when choosing page breaks.

2. **Control rich Detailed Description content**
   - Preserve the saved text, tables, formatting, and images dynamically.
   - Scale tables and ordinary images proportionally inside the Detailed Description width.
   - Prevent large embedded screenshots or document-page images from becoming a second full-size form or pushing later sections outside the reference geometry; render them as contained description attachments within the section instead.
   - Do not modify or delete the saved Detailed Description data.

3. **Keep the reference document framing on every page**
   - Render each PDF page independently rather than copying arbitrary vertical slices.
   - Continue long content across additional A4 pages with the same outer frame and correct margins.
   - Keep the three-column approval grid together where possible, followed by version-wise comments in their existing saved order.
   - Retain the current dynamic DRAFT/final behavior, page numbering, filename, logo, approval details, and comments.

4. **Leave all non-PDF behavior unchanged**
   - Do not change SAP calls, saved records, approval workflow, permissions, DOCX generation, Print, uploads, editing, or any other screen.
   - Limit changes to the PDF presentation and pagination path, with narrowly scoped PDF-only styling.
